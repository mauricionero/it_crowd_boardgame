# Modelo de tabuleiro

`board-model.html` imprime o tabuleiro principal em uma folha A4 paisagem.

O tabuleiro ocupa toda a largura disponível de 297 mm e é centralizado verticalmente para preservar a proporção original de 1672 × 941 px. Como a arte é mais larga que a proporção da folha A4, sobram margens brancas acima e abaixo.

Para imprimir, use escala de 100% e desative qualquer opção de “ajustar à página”.
